Unit Testing Generator One run, step by step

  1. Choose a file

    An interactive terminal menu takes the path to a Python file.

  2. Parse locally

    Python's ast library extracts valid, single-function blocks. Nothing else reaches the model.

  3. Prompt with rules

    A strict system prompt enforces Arrange, Act, Assert and mocks external dependencies.

  4. Call the model

    Llama-3.3 on the Groq API, driven through LangChain.

  5. Save the tests

    The pytest suite is written to the matching local directory with pathlib.

LLM tooling · Python

Automated Unit Testing Generator

View on GitHub ↗
Problem

Asking a language model for unit tests breaks down when the input is not a clean single function and when the model ignores testing conventions. Every failed attempt also costs an API call.

Approach
  • Built a Python command-line app that generates pytest scripts for any Python function using LangChain and the Groq API (Llama-3.3).
  • Parses source files locally with the ast library, so the model only receives valid, single-function code blocks. This prevents errors and cuts API calls.
  • Wrote strict system prompts that enforce the Arrange, Act, Assert standard and mock external dependencies correctly.
  • Added an interactive terminal menu that takes a file path and saves the new test suite in the matching local directory with pathlib.
